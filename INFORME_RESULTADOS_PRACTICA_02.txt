1. DESCRIPCION GENERAL DEL TRABAJO
======================================================================

El presente trabajo desarrolla una aplicacion en Python para visualizar dominios
geograficos mediante puntos reales, cuadriculas y mallas. La aplicacion fue
construida con Streamlit, Pandas, NumPy, Plotly, Matplotlib y ReportLab.

El objetivo principal es aplicar tecnicas basicas de visualizacion espacial a
partir de coordenadas de latitud y longitud. Para ello, el sistema permite:

- Cargar un archivo CSV geografico.
- Detectar columnas de ciudad, pais, latitud y longitud.
- Filtrar datos por pais.
- Filtrar datos por region/departamento.
- Filtrar datos por zona macro: Norte, Centro y Sur.
- Filtrar datos por region natural: Costa, Sierra y Selva.
- Filtrar datos por ciudad o localidad.
- Limpiar coordenadas vacias o inconsistentes.
- Calcular el dominio geografico rectangular.
- Graficar puntos reales.
- Generar una cuadricula regular.
- Construir una malla visual.
- Mostrar mapas interactivos con OpenStreetMap.
- Generar un informe PDF desde la misma aplicacion.

La aplicacion se encuentra en el archivo:

app.py

Para ejecutarla se puede usar:

python -m streamlit run app.py

Tambien se agrego un lanzador para Windows:

run_app.bat

6. DELIMITACION DEL DOMINIO GEOGRAFICO
======================================================================

El dominio geografico se construye a partir de los valores minimos y maximos de
longitud y latitud.

Definicion:

xmin = longitud minima
xmax = longitud maxima
ymin = latitud minima
ymax = latitud maxima

Dominio:

D = [xmin, xmax] x [ymin, ymax]

Resultados calculados para el dataset de muestra de Peru:

Parametro | Valor | Interpretacion
Longitud minima | -81.2719 | Limite occidental del dominio
Longitud maxima | -69.0417 | Limite oriental del dominio
Latitud minima | -18.0066 | Limite sur del dominio
Latitud maxima | -3.5669 | Limite norte del dominio

Dominio geografico resultante:

D = [-81.2719, -69.0417] x [-18.0066, -3.5669]

Interpretacion:

El dominio representa el rectangulo geografico que contiene todas las localidades
peruanas usadas en el analisis. Incluye puntos desde el norte del Peru hasta el
sur, y desde la costa occidental hasta zonas cercanas a la selva oriental.

14. RESPUESTAS DE LA ACTIVIDAD 7
======================================================================

a) Que representa el dominio geografico construido?

Representa el rectangulo geografico minimo que contiene las coordenadas reales
seleccionadas. En este trabajo, el dominio se define usando la longitud minima,
longitud maxima, latitud minima y latitud maxima de las localidades filtradas.
Si se trabaja con todo Peru, el dominio cubre el conjunto completo de ciudades
de la muestra. Si se filtra por region, el dominio se recalcula solo para esa
region.

b) Que diferencia existe entre los puntos reales y los puntos generados en la
cuadricula?

Los puntos reales provienen del dataset y representan ciudades o localidades
existentes. Los puntos generados en la cuadricula no son ciudades reales; son
posiciones creadas matematicamente con separaciones constantes dx y dy. Su
funcion es organizar el territorio y servir como referencia espacial.

c) Que utilidad tiene una malla en la visualizacion de datos espaciales?

La malla permite dividir el dominio en celdas visuales. Esto facilita comparar
zonas, ubicar puntos dentro de un territorio, observar concentraciones y apoyar
analisis relacionados con cobertura, distribucion, rutas o servicios. En la app,
la malla se visualiza tanto en un grafico cartesiano como sobre un mapa real.

d) Como podria aplicarse este tipo de visualizacion en un problema de Ingenieria
de Sistemas?

Puede aplicarse en problemas como:

- Analisis de cobertura de internet.
- Ubicacion de sensores IoT.
- Distribucion de usuarios de una plataforma.
- Diseno de rutas.
- Ubicacion de centros de atencion.
- Planificacion de servicios digitales.
- Monitoreo territorial.
- Toma de decisiones basada en datos geograficos.

Por ejemplo, una empresa podria usar una malla para decidir donde instalar
antenas, sensores o puntos de soporte tecnico, considerando la distribucion real
de usuarios o localidades.

15. RESPUESTAS A LAS PREGUNTAS DE ANALISIS
======================================================================

1. Por que es importante delimitar un dominio antes de construir una
visualizacion espacial?

Es importante porque permite definir el area exacta de estudio. Sin un dominio,
la visualizacion puede quedar desordenada, mostrar zonas que no pertenecen al
analisis o perder escala. Ademas, el dominio es necesario para generar una
cuadricula y una malla dentro de limites claros.

2. Que informacion aporta el grafico de puntos reales?

Aporta la ubicacion exacta de las ciudades o localidades del dataset. Permite
observar como se distribuyen los datos, donde hay mayor concentracion y que zonas
tienen menor presencia de registros.

3. Que representa una cuadricula de puntos en visualizacion de datos?

Representa una division regular del espacio mediante puntos generados con una
separacion constante. La cuadricula no representa datos reales, sino posiciones
de referencia que ayudan a organizar el dominio geografico.

4. Que diferencia existe entre una cuadricula y una malla?

La cuadricula esta formada por puntos generados dentro del dominio. La malla se
construye al unir esos puntos mediante lineas horizontales y verticales,
formando una estructura visual de celdas.

5. Que ocurre visualmente si se reduce el valor de dx y dy?

La cuadricula se vuelve mas densa porque se generan mas puntos. La malla tambien
tiene mas lineas y celdas pequenas. Esto aumenta el detalle, pero puede saturar
la visualizacion si los valores son demasiado bajos.

6. Que ocurre visualmente si se aumenta el valor de dx y dy?

La cuadricula se vuelve mas separada porque se generan menos puntos. La malla
tiene menos lineas y celdas mas grandes. Esto simplifica la visualizacion, pero
reduce la precision espacial.

7. Como puede ayudar esta visualizacion en la toma de decisiones dentro de
Ingenieria de Sistemas?

Ayuda porque relaciona datos con ubicaciones geograficas. En Ingenieria de
Sistemas puede utilizarse para planificar cobertura de redes, ubicar sensores,
analizar usuarios por territorio, disenar rutas, distribuir recursos y evaluar
zonas con mayor o menor atencion.
